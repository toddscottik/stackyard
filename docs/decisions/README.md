# Architecture decisions

Create a short numbered note only for a consequential choice or change, such as the provider contract, persistence authority, process ownership, package provenance, or routing topology. Routine implementation choices do not need a separate document.

Use `NNNN-short-name.md` with:

```text
Title:
Status: proposed / accepted / superseded
Context and concrete problem:
Decision:
Alternatives considered:
Consequences and compatibility impact:
Evidence / tests:
Supersedes (if any):
```

The coordinator assigns numbers and integrates decisions. A proposal does not override the current development plan until accepted within the task's authorized scope.
